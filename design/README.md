# Design file

`CAT_PYQ_Desk.fig` is the Figma design for the site: Home, Practice, Timed test, Review and a dark Timed test screen, plus the components, colour variables and text styles they use.

## Open it

1. Download [CAT_PYQ_Desk.fig](CAT_PYQ_Desk.fig?raw=1).
2. Go to [figma.com](https://www.figma.com) and sign in (a free account is enough).
3. Drag the file onto the Figma home screen, or use **Import** on that screen.

## What's inside

- **Screens:** Home, Practice, Timed test, Review, Timed test (dark).
- **Components:** Button, Answer option (5 states), Palette cell (CAT palette colours), Paper cell, Top bar.
- **Colours:** variables in two collections, `Color · Light` and `Color · Dark`.
- **Type:** Archivo for the interface, Lexend for questions and passages.
