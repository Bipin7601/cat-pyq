# CAT Previous-Year Questions

A practice site for CAT 2020–2025 previous-year questions.

- Practice by topic, with multi-select and a live tally.
- Timed full and sectional tests, with review afterwards.

Live site: https://bipin7601.github.io/cat-pyq/

## Run locally

```
python3 -m http.server
```

Run it in the repo root, then open http://localhost:8000.

## Run tests

```
node --test
```

## Content

Questions are from past CAT papers; answers are the official keys; explanations are original.

Every question, including all DILR sets, has an explanation.
